# Jeżyce ↔ Sołacz — landing poparcia

Statyczna strona kampanii obywatelskiej: bezpieczne przejście pieszo-rowerowe pod torami (linia 351) przy ul. św. Wawrzyńca w Poznaniu, łączące Jeżyce z Sołaczem.

## Co to jest

- `index.html` — samowystarczalny landing (inline CSS, minimalny JS). Hero losowany z 12 wizualizacji przy każdym wejściu.
- `hero/hero-01..12.jpg` — wizualizacje poglądowe (ilustracje AI), losowane na load.
- `hero.jpg` — obraz OG (podgląd na Facebooku) i fallback hero.

## Hosting

GitHub Pages (branch `main`, katalog `/`). Docelowo domena **jezyce-solacz.pl** (CNAME + DNS).
